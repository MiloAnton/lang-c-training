Règles de présentation exigées
  • un titre de programme encadré ou souligné au lancement ;
  • des invites de saisie qui disent ce qui est attendu (unité, bornes, format) ;
  • une ligne vide entre la saisie et les résultats ;
  • des résultats alignés, avec leurs unités, et 2 décimales pour tout montant ;
  • des messages d'erreur explicites qui disent ce qui ne va pas et ce qu'il faut faire ;
  • aucun texte collé au prompt du terminal en fin de programme.

Ton exécution doit ressembler à l'exemple fourni sous chaque énoncé.

Certains exercices demandent des options de compilation (-D, -E) ou un Makefile : pour ceux-là, travaille sur ta machine.

BOSS 2

Le système de logs à niveaux

Crée LOG_ERREUR, LOG_AVERT, LOG_INFO et LOG_DEBUG avec couleurs ANSI dans le terminal. Le niveau minimal est choisi à la compilation (-DNIVEAU_LOG=1) et les messages inférieurs disparaissent totalement du binaire. Vérifie-le avec gcc -E.

Exemple d'exécution
$ gcc logs.c -o logs && ./logs
=== LOGS À NIVEAUX (NIVEAU_LOG = 3) ===

[DEBUG ] logs.c:41 connexion à la base : tentative 1
[INFO  ] logs.c:42 serveur démarré sur le port 8080
[AVERT ] logs.c:43 disque rempli à 85 %
[ERREUR] logs.c:44 impossible d'ouvrir config.ini

$ gcc -DNIVEAU_LOG=1 logs.c -o logs && ./logs
=== LOGS À NIVEAUX (NIVEAU_LOG = 1) ===

[AVERT ] logs.c:43 disque rempli à 85 %
[ERREUR] logs.c:44 impossible d'ouvrir config.ini

(Chaque étiquette s'affiche dans sa couleur : gris, bleu, jaune, rouge.)

La version démo et la version premium

Un même code source produit deux exécutables selon une option de compilation. La version démo limite le carnet de contacts à 5 entrées et affiche un bandeau. Aucun if à l'exécution pour choisir la version : tout se joue au préprocesseur. Ajoute les deux cibles au Makefile.

Exemple d'exécution
$ make
$ ./carnet_demo
***************************************************
*  VERSION DÉMO : 5 contacts maximum.             *
*  Passez à la version Premium pour 100 contacts. *
***************************************************
=== CARNET Démo ===
...
Votre choix : 1
>> Limite de 5 contacts atteinte (version Démo).

BOSS 5

Le chasseur de bugs de macros

Voici 6 macros buguées. Pour chacune, déclenche le bug, explique-le, puis corrige-la. Écris un programme qui affiche le résultat bugué et le résultat corrigé.

#define DOUBLE(x) x + x                         /* 3 * DOUBLE(2) */
#define CARRE(x) (x * x)                        /* CARRE(1 + 2) */
#define MAX(a, b) ((a) > (b) ? (a) : (b))       /* MAX(i++, j) */
#define PI 3.14159;                             /* PI * r * r */
#define AFFICHER_ERREUR(msg) printf("Erreur : "); printf("%s\n", msg)
                                                /* if (!ok) AFFICHER_ERREUR("..."); */
#define ABS(x) x < 0 ? -x : x                   /* ABS(a - b) */
Exemple d'exécution
=== CHASSEUR DE BUGS DE MACROS ===

1. 3 * DOUBLE(2)    bug : 8   corrigé : 12
2. CARRE(1 + 2)     bug : 5   corrigé : 9
3. MAX(i++, j)      bug : 6 (i vaut ensuite 7)   corrigé : 5 (i vaut ensuite 6)
4. Aire du cercle   corrigé : 12.57 (sans ; dans le #define)
5. Erreur affichée alors que ok = 1 ?
disque plein
   (ci-dessus : la version bug a quand même affiché la 2e moitié)
   (version corrigée : rien ne s'affiche)
6. ABS(a - b)       bug : -9   corrigé : 5
