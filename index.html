Entraîne-toi au C, du binaire aux threads

285 exercices en 19 chapitres, en trois niveaux : échauffement, intermédiaire et BOSS. Tu écris ton code, tu l'exécutes et tu le vérifies directement dans ton navigateur, sans rien installer.

Comment ça marche

  1. Lis l'énoncé et l'exemple d'exécution : ton programme doit afficher la même chose, présentation comprise.
  2. Écris ta solution dans la zone de code de l'exercice, puis clique sur Exécuter (ou Ctrl+Entrée). Le programme te demande tes saisies comme dans un vrai terminal.
  3. Vérifie : le bouton « Vérifier mon programme » relance ton code avec les saisies de l'exemple et te montre les lignes qui diffèrent.
  4. Bloqué ? Les indices puis la correction se débloquent avec le code donné en séance.

La première exécution télécharge le compilateur (environ 27 Mo), une seule fois : il reste ensuite en mémoire dans ton navigateur. Ton code est enregistré automatiquement sur cet appareil.

Règles de présentation exigées sur tous les exercices
  • un titre de programme encadré ou souligné au lancement ;
  • des invites de saisie qui disent ce qui est attendu (unité, bornes, format) ;
  • une ligne vide entre la saisie et les résultats ;
  • des résultats alignés, avec leurs unités, et 2 décimales pour tout montant ;
  • des messages d'erreur explicites qui disent ce qui ne va pas et ce qu'il faut faire ;
  • aucun texte collé au prompt du terminal en fin de programme.
