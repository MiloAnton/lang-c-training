# Langage C : entraînement

[https://miloanton.github.io/lang-c-training/index.htm]Accéde au site ici !

Site d'entraînement au langage C de Leonis Formation : 285 exercices en 19 chapitres, compilation et exécution dans le navigateur, vérification automatique de la sortie.

Les indices et les corrections sont chiffrés dans les pages et se débloquent avec les codes donnés en séance.

Compilateur : Clang/LLD compilé en WebAssembly par le projet YoWASP (https://yowasp.org, licence ISC, LLVM sous licence Apache 2.0 avec exception LLVM). Éditeur : CodeMirror 5 (licence MIT).
