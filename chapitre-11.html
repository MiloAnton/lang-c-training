Règles de présentation exigées
  • un titre de programme encadré ou souligné au lancement ;
  • des invites de saisie qui disent ce qui est attendu (unité, bornes, format) ;
  • une ligne vide entre la saisie et les résultats ;
  • des résultats alignés, avec leurs unités, et 2 décimales pour tout montant ;
  • des messages d'erreur explicites qui disent ce qui ne va pas et ce qu'il faut faire ;
  • aucun texte collé au prompt du terminal en fin de programme.

Ton exécution doit ressembler à l'exemple fourni sous chaque énoncé.

Dans le navigateur, le programme tourne sur une machine 32 bits : sizeof(long) et la taille d'un pointeur y valent 4 (8 sur ton PC). Pour les tableaux de tailles, compile aussi sur ta machine.

BOSS 2

Le portage multi-plateforme

Un collègue a écrit ce programme qui suppose qu'un int fait 4 octets partout. Réécris-le pour qu'il soit portable : sizeof partout, un typedef Score, et un message d'avertissement si la plateforme ne correspond pas à ce qu'il avait supposé.

int main(void)
{
    int scores[10] = {12, 45, 7, 88, 23, 51, 9, 30, 66, 14};
    int copie[10];
    int nb = 40 / 4;
    int i;

    memcpy(copie, scores, 40);
    printf("Le tableau occupe 40 octets\n");
    for (i = 0; i < nb; i++) {
        printf("%d ", copie[i]);
    }
    printf("\n");
    return 0;
}
