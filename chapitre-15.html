15Bibliothèques et modularité (.h / .c)

Règles de présentation exigées
  • un titre de programme encadré ou souligné au lancement ;
  • des invites de saisie qui disent ce qui est attendu (unité, bornes, format) ;
  • une ligne vide entre la saisie et les résultats ;
  • des résultats alignés, avec leurs unités, et 2 décimales pour tout montant ;
  • des messages d'erreur explicites qui disent ce qui ne va pas et ce qu'il faut faire ;
  • aucun texte collé au prompt du terminal en fin de programme.

Ton exécution doit ressembler à l'exemple fourni sous chaque énoncé.

BOSS 5

Le travail en équipe

Par binôme, on vous donne uniquement ce fichier banque.h. L'un écrit banque.c, l'autre écrit un main.c qui l'utilise, sans se montrer leur code. Les deux parties doivent compiler et fonctionner ensemble du premier coup.

#define BANQUE_OK 0
#define BANQUE_ERREUR_MONTANT 1
#define BANQUE_ERREUR_SOLDE 2
#define BANQUE_ERREUR_PLEIN 3
#define BANQUE_ERREUR_INTROUVABLE 4

#define BANQUE_MAX_COMPTES 50

typedef struct {
    int numero;
    char titulaire[40];
    long soldeCentimes;
} Compte;

/* Remet la banque à zéro (aucun compte). */
void banqueInitialiser(void);

/* Ouvre un compte avec un dépôt initial (>= 0). Écrit le numéro attribué dans *numero. */
int banqueOuvrirCompte(const char *titulaire, long depotCentimes, int *numero);

/* Dépose un montant strictement positif. */
int banqueDeposer(int numero, long montantCentimes);

/* Retire un montant strictement positif, sans découvert. */
int banqueRetirer(int numero, long montantCentimes);

/* Vire un montant d'un compte à un autre, sans découvert. */
int banqueVirer(int source, int destination, long montantCentimes);

/* Renvoie l'adresse du compte (lecture seule) ou NULL s'il n'existe pas. */
const Compte *banqueConsulter(int numero);

/* Renvoie un message lisible pour un code d'erreur. */
const char *banqueMessage(int code);
Exemple d'exécution
=== BANQUE DU BINÔME ===

Ouverture Alice : Opération réussie.
Ouverture Bob   : Opération réussie.
Retrait Bob 50 € : Solde insuffisant.
Virement Alice -> Bob 120 € : Opération réussie.
Dépôt de -10 € chez Alice : Montant invalide.
Retrait sur le compte 9999 : Compte introuvable.

État des comptes :
  Compte 1001 | Alice        |   380.00 €
  Compte 1002 | Bob          |   140.00 €
